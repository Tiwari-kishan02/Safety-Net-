# SafetyNet+

Real-time digital protection — verify contacts, detect phishing, and recover compromised accounts, all from one intelligent dashboard.

## Features
- **Column A:** Scam Number Checker
- **Column B:** Fake OTP/Message Detector
- **Column C:** Fake Email Detector
- **Column D:** Hacked Account Recovery Assistant

## Tech Stack
Python, Flask, Scikit-learn, HTML/CSS/JS
